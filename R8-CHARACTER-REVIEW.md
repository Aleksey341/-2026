# R8: проверка персонажа и экспорта, 2026-10-14

## Фактический результат

Версия генерации подтверждена повторным использованием сохранённого запроса созданного текстурированного ассета: selector вернулся с Meshy 6 Lite на Meshy 7.1 Flagship, стандартное разрешение, текстуры и улучшение изображения включены. Проверка версии не запускала новую генерацию.

Сохранена настоящая миниатюра результата Meshy (256x256). Это один ракурс примерно в три четверти; она не заменяет фронтальный, боковой, задний вид и крупный план лица. Видны белая рубашка, синий галстук, тёмные брюки, обувь и общие пропорции. Сходство лица, кисти, часы, UV, пересечения и обратная сторона не подтверждены. Ограничение просмотра установлено по ошибкам браузера: THREE.WebGLRenderer / Error creating WebGL context, GL_VENDOR=Disabled, GL_RENDERER=Disabled.

Интерфейс текстурированной исходной модели: 491868 треугольников, 264629 вершин. Бесплатная стандартная предварительная обработка через панель rig (10K, треугольники, цена 0) завершилась отдельным ассетом: 10311 треугольников, 12036 вершин. Баланс остался 210. Исходная модель сохранена. Выбор 30K вызвал paywall remesh, подписка не оформлялась.

После обработки открыт мастер humanoid rig: он требует проверить центрирование и направление лица; предлагаемая высота 1.7 м. Работа остановлена на проверке ориентации из-за пустого WebGL-просмотра. Кости, веса и результат деформаций пока не получены и не проверены. Уменьшение числа треугольников не доказывает пригодность топологии для rig.

## Экспорт

| Вариант | Установленный статус |
| --- | --- |
| Существующая Meshy 7.1 GLB | Скачать открывает предложение подписки. Бесплатный экспорт сейчас недоступен. |
| Meshy 6 Lite | Доступен в selector. Форма новой геометрии показывает 10 кредитов. Генерация не запускалась. |
| Переключить существующий ассет на Lite | Selector относится к новой генерации; ранее созданный ассет остаётся Meshy 7.1. |
| Бесплатные скачивания Lite | Официальная справка: до 10 скачиваний в месяц для моделей, созданных Lite. Остаток download allowance аккаунта не установлен. |
| Дополнительные текстуры Lite | Возможное отдельное текстурирование: справка указывает 10 кредитов для 2K/4K; доступность и цена должны быть проверены после получения Lite геометрии. |
| Готовый внешний GLB/FBX | Можно принять настоящий файл и выполнить проверку/интеграцию без подписки Meshy. |

Источники: https://help.meshy.ai/en/articles/15696428-what-is-included-on-the-free-plan и https://help.meshy.ai/en/articles/10000507-how-many-credits-does-each-generation-task-cost . Стоимость интерфейса имеет приоритет над таблицей справки. Free-модели имеют CC BY 4.0, при использовании требуется указать Meshy.

Конкретный бесплатный путь: согласовать одну генерацию Lite за 10 бесплатных кредитов; затем проверить экспорт и отдельно согласовать текстурирование, если понадобится. Для осмотра текущей модели открыть существующий результат в собственном браузере с WebGL и получить фронтальный/боковой/задний ракурс и лицо, без повторной генерации. Изображения не считать заменой файлу GLB.

## Исходники R8

Добавлены отдельные файлы: game/tools/extract_r7.py, game/src/character-animation-r8.js, game/tools/test_character_animation_r8.mjs. Ни START-HERE-R7.html, ни существующие runtime-модули не изменены; compare GitHub подтверждает только добавленные файлы в ветке character-upgrade-r8.

extract_r7.py восстанавливает опубликованные 12 модулей и 50 ассетов, config, исходную baseline-R7.html, страницу разработки с внешними importmap URL и manifest SHA256. Сверены hashes всех извлечённых файлов, разрешение import dependencies и HTTP 200 страницы. Визуальная проверка этой основы ещё не выполнена.

CharacterAnimationR8 использует только supplied clips для девяти состояний, проверяет наличие уникальных непустых clips, делает crossfade, учитывает фактическую скорость после коллизий, сбрасывается при телепорте. Требуется калиброванная скорость Walk. Процедурных суставных движений и фиктивной GLB нет. Модуль пока не подключён к AssetSystem. Проверки выполнены с реальным Three.js AnimationMixer: запуск/остановка, изменение phase rate, остановка при нулевой скорости, прерывание старта, поворот, жест, телепорт, dispose. Команда: node game/tools/test_character_animation_r8.mjs.

Тесты контроллера не подтверждают естественность реальной походки и контакт стоп. Релиз R8 не готов. PR #8 остаётся draft; merge не выполнялся.
