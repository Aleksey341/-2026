# Итоги 2026 — Backroom Office

Интерактивный браузерный 3D-прототип для ежегодного подведения итогов ЦК БОРУЛ.

## Что уже реализовано

- стартовая заставка «Итоги 2026»;
- центральный HR HUB;
- три демонстрационные зоны: «Приём», AI LAB и «Наставничество»;
- интерактивные терминалы;
- прогресс прохождения 0/3 → 3/3;
- закрытый портал 2027, который открывается после прохождения всех трёх зон;
- placeholder-показатели `XX` / `XXXX`, чтобы не подменять фактические итоги 2026 данными 2025 года;
- управление WASD + мышь + E;
- базовая инициализация WebXR для совместимых браузеров и VR-устройств.

## Запуск локально

Проект статический, сборка пока не нужна.

### Через Python

```bash
python -m http.server 8080
```

После этого открыть:

```text
http://localhost:8080
```

### Через VS Code / Cursor

Можно использовать расширение Live Server и открыть `index.html` через него.

## Управление

- `W A S D` — движение;
- мышь — обзор;
- `E` — взаимодействие;
- `Esc` — освободить курсор;
- клик по сцене — снова захватить курсор.

## Где лежат данные 2026

Контент вынесен в `src/data.js`. Когда появятся реальные итоги 2026, будем менять прежде всего этот файл, не переписывая всю 3D-сцену.
