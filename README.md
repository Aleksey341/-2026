## R7

- Тёмные слайды, полноэкранный просмотр, проекция на стене
- Парящий стол и пять дронов в комнате будущего
- В комнате 3: фиолетовая кнопка слева на стене напротив лифта → слайд → «Рассмотреть»
- В витринах стрелка возврата отмечает слайд просмотренным

Управление: WASD / стрелки, зажатая мышь — осмотр, колесо — приближение, E — действие.
