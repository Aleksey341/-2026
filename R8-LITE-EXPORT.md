# R8: Meshy 6 Lite и подготовка тестовой сцены

Дата: 2026-10-14. Генерация согласована пользователем: одна операция, 10 бесплатных кредитов.

## Результат

Выполнена ровно одна генерация Meshy 6 Lite по оригинальному изображению 00_ORIGINAL_front_transparent.png. Форма Lite принимает один основной ракурс; дополнительных multiview-полей нет. Вспомогательные изображения сохранены для оценки результата. Остаток кредитов изменился с 210 на 200. Дополнительные операции, подписка, текстурирование и повторная генерация не запускались. Модель 7.1 и её отдельная уменьшенная копия сохранены; Lite основным игровым персонажем не назначена.

ID созданной задачи Lite: 01a13c34-59cd-7182-a004-6defccfd124d. Сохранена настоящая миниатюра. Интерфейс показывает 67642 треугольника, 33817 вершин. Lite создан без текстур. На миниатюре виден мужчина в деловой одежде; оценка сходства лица, кистей и обратной стороны по этому разрешению невозможна. Полноценная геометрическая проверка требует файла.

## Экспорт

В панели скачивания новой Lite-модели выбран glb; кнопка Скачать доступна и рядом показано x10 вместо PRO. При попытке скачивания событие download не завершилось, затем браузер явно сообщил, что протокол URL не разрешён (допустимы http/https). Обходов политики, получения внутренних URL и повторных попыток скачивания через альтернативный клиент не выполнялось. Экспорт доступен на уровне тарифа, но файл в рабочую папку не получен. Проверка GLB и наличия скелета этой модели не выполнена. Точный протокол заблокированного URL инструмент не сообщил.

Продолжение: пользователь скачивает созданную серую модель Meshy 6 Lite в своём обычном браузере через GLB и прикрепляет файл. Новой генерации для этого не нужно. После получения файла можно выполнить локальный осмотр, проверку skins/weights/animations и снять реальные ракурсы, не используя WebGL облачного браузера.

## Тестовая сцена

Добавлены game/character-lab-r8.html и game/src/character-lab-r8.js. Страница позволяет открыть настоящий локальный GLB, смотреть фронт/бок/спину/лицо, выбирать встроенный клип и тестировать управление. Модель не передаётся во внешний сервис. Сцена не связана с опубликованной R7 и не меняет персонажа игры.

Полный тест управления включается только при наличии skinned meshes и всех девяти подготовленных клипов. Используется CharacterAnimationR8, crossfade, фактическая скорость после ограничения движения, плавный разворот. Поворот на месте тестируется на 90 градусов с привязкой к длительности TurnLeft/TurnRight; величину нужно сверить с реальными клипами. Синусоидальных суставных анимаций нет. Если GLB статичен, сцена честно показывает отсутствие скелета и оставляет только осмотр геометрии. Походка мужчины ещё не проверена и не реализована на реальном GLB.

Для локального запуска: из корня репозитория python3 -m http.server 8000 --directory game, затем http://localhost:8000/character-lab-r8.html . Для Walk нужно указать измеренную скорость исходного клипа; значение 1.4 в поле лишь начальный параметр.

## Локальный рендер

Добавлен game/tools/render_character_r8.py: создаёт четыре bind-pose изображения 768x768 и JSON-отчёт (размеры, meshes, materials, skins, joints, animations). Входной GLB не меняется. Зависимости: trimesh, pyrender, pygltflib, numpy, Pillow и PyOpenGL; для Python 3.12 проверена версия PyOpenGL 3.1.10. PYOPENGL_PLATFORM=egl позволяет работать без browser WebGL.

Инструмент проверен на существующей heroine-purple-walk.glb R7: все четыре изображения созданы, видимая текстурированная геометрия подтверждена, обнаружены 1 skin и 1 animation. Этот тест относится только к прежней модели; выводы о мужчине на его основании не делаются.

Проверки исходников: node --check game/src/character-lab-r8.js прошёл; node game/tools/test_character_animation_r8.mjs прошёл. Интерактивная проверка страницы с настоящим мужским GLB пока не выполнена. R7 сохранена, PR #8 остаётся draft; merge отсутствует.
