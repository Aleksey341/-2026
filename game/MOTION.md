# R5.2: движения персонажа

Изменения относятся к веб-версии `game/` и обеим моделям героини.

- `src/character-motion.js`: ускорение/торможение, подготовка первого шага,
  чередование переноса и опоры, прогноз точки постановки стопы по фактической
  скорости, завершение шага при остановке, переступание при поворотах.
- Двухзвенная IK для бедра и голени. Стопа в опоре закреплена в мировых
  координатах; таз опускается в пределах досягаемости ноги. При смене комнаты,
  модели или перезапуске опоры сбрасываются.
- Перекат пятка/носок выполняется вращением стопы вокруг точки контакта.
  Отдельных костей пальцев ног в исходных моделях нет.
- Перенос веса, контрвращение таза и плеч, размах противоположной руки,
  запаздывание предплечья и кисти, небольшая асимметрия рук.
- Плавный взгляд в направлении движения и объектов взаимодействия,
  компенсация наклона корпуса головой и небольшие движения в покое.
  VR-очки следуют положению и повороту головы.
- Максимальная скорость сохранена: 1,65 м/с. Во время резкого разворота она
  уменьшается. Коллизии используют фактическое перемещение: шаги прекращаются
  у препятствия. Пауза замораживает позу.

## Проверки

Из корня репозитория, Node.js 24:

```sh
node --test game/tests/character-motion.test.mjs
```

Тесты читают обе настоящие GLB-модели через штатный GLTFLoader без загрузки
текстур. Проверяются опорные точки, ошибка IK, завершение остановки, разворот
на 180°, коллизии, пауза, перенос в другую комнату, взгляд, нормализация
кватернионов, скорость при 30/60/120 FPS. Дополнительно CPU skinning проверяет
высоту вершин обуви при ходьбе и повороте на 30 FPS.

В проверенных сценариях: 7 тестов пройдены, сдвиг опорной точки 0,
ошибка IK при прямой ходьбе менее 1e-12 м, минимальная высота сетки белой
героини около -0,00175 м (фиолетовой — около нуля).

Это численная проверка, не визуальная приёмка. Проверочный браузер не смог
создать WebGL-контекст. Визуально нужно оценить походку спереди и сбоку,
старт/остановку, короткие нажатия, повороты, взгляд на очки и витрины,
посадку VR-очков, обе модели и движение вдоль мебели.

## Автономные версии

Существующие `Play-offline.html` и `START-HERE-R5.html` — прежние снимки R5.
Для новой автономной сборки:

```sh
python game/build_offline.py
```

Сборщик включает новый модуль автоматически и создаёт `game/Play-offline.html`.
Корневой `START-HERE-R5.html` сам по себе не обновляется.
