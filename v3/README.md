# v3.4 · CLEAN CINEMATIC BUILD

Параллельная чистая сборка проекта «Итоги 2026» для ЦК БОРУП.

## Правило подачи данных

В 3D-пространстве нет таблиц, названий блоков, KPI или чисел. Все названия, пояснения и показатели показываются только на информационном табло конкретного блока (`storyCard`). Финальная информация 2027 показывается только на финальном табло (`finale`).

## Статус

1. **Архитектура** — чистая сборка без цепочки v10–v31.
2. **Автомобиль** — premium GLB-концепт с процедурным fallback. Это визуальный концепт 2027, не официальный Ferrari 2027.
3. **Процессные мини-сцены** — предметные сцены без пространственного текста и без визуального кодирования KPI количеством объектов.
4. **Трасса** — в v3.4 разбита на визуально разные районы, чтобы поездка воспринималась как переход между реальными средами, а не как один повторяющийся неоновый тоннель.
5. **Два режима запуска** — автоматическая презентация и свободная поездка.
6. **Финал 2027** — портал, частицы и открытая площадка без пространственного текста; вся смысловая информация находится на финальном табло.
7. **WebXR** — базовая интеграция сохранена; финальная проверка требует реального Quest.

## Изменения v3.4

- Добавлен `district-world-v34.js`.
- Большая часть одинаковых световых колец старой трассы отключена; сохранены только отдельные световые рамки как редкие кинематографические акценты.
- Каждый участок получил собственную архитектуру и атмосферу:
  - **Приём** — зона прибытия с навесами, проходами и холодным голубым светом;
  - **Кадровый конвергент** — стеклянные сервисные павильоны, стойки и спокойный зелёно-бирюзовый свет;
  - **ИИ-команда** — исследовательский кампус с лабораторными корпусами и переходом над дорогой;
  - **Корпоративные награды** — открытый церемониальный бульвар с тёплым светом и колоннами;
  - **Вредные условия труда** — индустриальная зона с ограждениями, контрольным освещением и технологическими башнями;
  - **2027** — пространство постепенно раскрывается, становится шире и переходит в финальную площадку.
- Цвет неба, тумана и интенсивность свечения плавно меняются по мере движения между районами.
- Названия районов и KPI по-прежнему не выводятся в 3D: информационный слой остаётся только на табло.
- Runtime поднят до `3.4.0`.

## Тестовый URL

GitHub Pages: `/v3/?v=3401`

Для VR-калибровки можно временно открыть, например, `/v3/?v=3401&vrY=1.20&vrZ=0.08`.

До отдельного решения пользователя корневой production-маршрут не заменяется: v3 развивается параллельно и может быть продвинут в `/` после тестирования.
