# v3 · CLEAN CINEMATIC BUILD

Параллельная чистая сборка проекта «Итоги 2026» для ЦК БОРУП.

## Статус 6 направлений

1. **Архитектура** — начато: новая сборка больше не зависит от цепочки v10–v31. Основные модули: `core.js`, `vehicle.js`, `route.js`, `presentation.js`, `xr.js`.
2. **Автомобиль** — подготовлен GLB-loader и рабочий процедурный fallback. Следующий подэтап: вставить проверенную лицензированную GLB-модель и настроить масштаб/колёса/салон.
3. **Мини-сцены результатов** — начато: для 5 подтверждённых блоков 2025 созданы отдельные 3D-сцены. Контент подаётся как «задача → что сделали → результат».
4. **Два режима запуска** — реализовано: автоматическая презентация (~7 минут с 65-секундными остановками на блоках и возможностью нажать «ДАЛЬШЕ») и свободная поездка.
5. **Финал 2027** — начато: отдельный энергетический коридор и финальный экран. Неподтверждённые цели 2027 не выдумываются.
6. **WebXR** — чистая базовая интеграция: проверка `immersive-vr`, VR-кокпит, 3D-панель, управление левым стиком и триггером.
