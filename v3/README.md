# v3.2 · CLEAN CINEMATIC BUILD

Параллельная чистая сборка проекта «Итоги 2026» для ЦК БОРУП.

## Статус

1. **Архитектура** — чистая сборка без цепочки v10–v31.
2. **Автомобиль** — premium GLB-концепт с процедурным fallback. Это визуальный концепт 2027, не официальный Ferrari 2027.
3. **Мини-сцены результатов** — 3D-сцены остаются визуальными и не содержат вынесенных в пространство таблиц, названий или чисел.
4. **Два режима запуска** — автоматическая презентация и свободная поездка.
5. **Финал 2027** — пространственный портал и площадка без 3D-текста; вся текстовая информация финала показывается только на финальном табло.
6. **WebXR** — базовая интеграция сохранена; финальная проверка требует реального Quest.

## Изменения v3.2

- Добавлен `clean-display-v32.js`: удаляет остаточные DOM-лейблы старых пространственных модулей и отключает известные 3D-текстовые объекты.
- Добавлен `clean-display-v32.css`: скрывает дублирующее название текущего блока в HUD и делает `storyCard` единственным информационным табло блока.
- Из `finale-2027.js` удалены пространственные надписи `2026` и `2027`; в 3D остаются только свет, портал, частицы и геометрия.
- Все названия блоков, описания, цифры и KPI показываются на `storyCard` конкретного блока. Финальный текст 2027 — только на `finale`.
- Служебный бейдж загрузки автомобиля автоматически убирается после старта.

## Тестовый URL

GitHub Pages: `/v3/?v=3201`

Для VR-калибровки можно временно открыть, например, `/v3/?v=3201&vrY=1.20&vrZ=0.08`.

До отдельного решения пользователя корневой production-маршрут не заменяется: v3 развивается параллельно и может быть продвинут в `/` после тестирования.
