# v3 assets

Для этапа 2 предусмотрена замена процедурного автомобиля на лицензированную/принадлежащую проекту GLB-модель.

Ожидаемый путь по умолчанию:

`v3/assets/supercar-2027.glb`

Загрузка уже реализована в `vehicle.js` через `HR3.vehicle.loadPremiumModel()`.

До добавления проверенного GLB используется процедурный fallback, чтобы сборка v3 оставалась полностью рабочей и не зависела от внешнего ассета.
