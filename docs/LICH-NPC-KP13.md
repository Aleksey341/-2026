# КП1.3 — Витражный лич: промежуточная модель со встроенными анимациями

**Назначение:** отдельный интерактивный NPC в зале активации, не заменяет управляемую героиню.

## Фактически создано

Пакет для пользователя: `BORUP2026_Lich_KP13_Animated_NPC.zip`. Содержит действительный бинарный файл `assets/characters/stained-glass-lich/lich_kp13_animated_npc.glb` (≈1,40 МБ), исходник геометрии, скрипт запекания клипов, независимый валидатор GLB, лабораторию Three.js, четыре статических позы и GIF/MP4 предпросмотр анимации.

GLB: 34 128 треугольников, 18 материалов, 3 встроенные видеотекстуры, 47 mesh-примитивов. **5 записанных клипов** `Idle`, `Greet`, `Cast`, `LookAround`, `StaffIdle`.

**Тип анимационного устройства:** четыре жёстких локальных узла `LichHeadPivot`, `LichLeftArmPivot`, `LichRightArmPivot`, `LichStaffPivot`; клипы содержат настоящие glTF animation samplers / keyframes. Это **не humanoid-armature, нет SkinnedMesh и весов вершин**, рука сгибается единым сегментом, ткань не деформируется. Настоящая профессиональная анимация и улучшение внешности обязательны до финальной приёмки.

## Код игры

В `room-module/src/lich-npc.js` путь обновлён на новый GLB. На `open()` запускается `Greet`; при вопросе о реакторе — `Cast`; по завершении клипа и закрытии диалога — `Idle`. Интеграция хранится в отдельной ветке. Рабочая R16 в `main` не изменена.

В `character-lab-lich.html` добавлена попытка автоматически загрузить файл из `assets/characters/stained-glass-lich/lich_kp13_animated_npc.glb` после его публикации в ветке; ручной выбор GLB сохранён.

## Проверки

1. GLB 2.0: корректная длина чанков и таблиц данных.
2. Каждая анимация: возрастающие таймкоды, единичные кватернионы, привязка каналов к правильным pivot-node, отсутствие конфликтующей `matrix` на анимируемых узлах.
3. 3D-сетка импортируется в Trimesh без потери геометрии.
4. Четыре позы реально визуализированы из GLB средствами VTK; подготовлен демонстрационный ролик.
5. PR11: `Lich NPC prototype checks` и `R15 lift and entry smoke test` прошли после синхронизации `source/game.js` с активной копией.

**Не проверено:** запуск GLB через GLTFLoader в Chromium/Edge (локальный браузер блокирует URL с ошибкой `ERR_BLOCKED_BY_ADMINISTRATOR`), фактическое взаимодействие в игровом зале, работа на мобильном, плавность ткани, соответствие оригинальному видео.

## Блокирующий шаг перед визуальной интеграцией

Двоичный GLB **ещё не помещён в GitHub**. Из подготовленного ZIP можно запустить `PUBLISH-GLB-TO-GITHUB.bat`: он проверит модель, скопирует её и отправит ТОЛЬКО в `feature/lich-character-r16` после ручного подтверждения. До этого NPC корректно сообщает об ошибке загрузки модели.
