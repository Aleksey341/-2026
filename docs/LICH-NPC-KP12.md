# КП1.2 · Витражный лич по кадрам видео

## Статус
- **Роль подтверждена:** отдельный интерактивный NPC в зале активации, основная героиня не заменяется.
- **Реальный файл GLB создан локально:** `lich_kp12_video_textured.glb`, размер 1 382 672 байта, glTF 2.0.
- **Структура:** 34 128 треугольников, 29 меш-примитивов, 18 материалов, 3 встроенных текстуры, частичная UV-развёртка.
- **Происхождение текстур:** пользовательское видео (в частности, кадр на ~53-й секунде), центральная и боковые секции мантии. Эти детали наложены на объёмную 3D-геометрию, а не на billboard.
- **Анимация:** 0 клипов, skin 0, кости 0. Ограниченная процедурная анимация ожидания в JS используется только как временная демонстрация.
- **Внешнее сходство:** пока неполное; реконструкция ручная, из MP4 не извлекался исходный 3D-меш.
- **Проверки:** GLB загружается стандартным glTF-парсером; 4 вида реально визуализированы через VTK. Внешность ещё не согласована.

## Интеграция в R16
В ветке `feature/lich-character-r16` добавлены `room-module/src/lich-npc.js` и вызовы в `room-module/src/game.js`. Реализованы:
1. Независимый NPC в зале активации, не блокирующий прогресс витрин.
2. Асинхронная загрузка внешнего `assets/characters/stained-glass-lich/lich_kp12_video_textured.glb`.
3. Радиус разговора 2.4 м, кнопка E/мобильная кнопка действия.
4. Диалог «Кто вы?», «О зале», «Для чего реактор?», «До встречи», закрытие Escape.
5. При наличии реальных клипов в будущем автоматически воспроизводится Idle.
6. Если файл GLB не загружен, NPC скрыт, ошибка записывается в консоль, основная игра продолжает работать.

**Блокер:** бинарный GLB пока не загружен в GitHub-ветку; он находится в архиве `BORUP2026_Lich_KP12_VideoBased_NPC.zip`, переданном пользователю. В ZIP есть скрипт `PUBLISH-TO-GITHUB.bat` для отправки модели в ветку, без изменения main.

## Ограничения качества
- Сетка не похожа достаточно точно на скелет из видео; нужна более качественная многовидовая генерация 3D/ручная скульптура.
- Из видео доступны преимущественно фронтальные ракурсы; спина восстановлена приблизительно.
- У модели отсутствует гуманоидный риг, поэтому анимации ходьбы/жеста не готовы.
- WebGL-просмотр игрового проекта из текущей среды блокируется; сквозная визуальная проверка в Chrome/Edge не проводилась.
